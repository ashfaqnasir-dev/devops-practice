## 🎯 Purpose

Networking concepts samajhna jo DevOps mein zaroori hain:

- **OSI Model** — 7 layers of network communication
- **TCP/IP** — Internet ka foundation
- **CIDR** — IP addressing aur subnets

## 📖 Key Learnings

### OSI Model
- 7 layers (Application → Physical)
- Har layer ka function
- Protocols per layer

### TCP/IP
- TCP vs UDP
- IPv4 vs IPv6
- Subnetting
- Ports & Sockets
- Three-way handshake

### CIDR Notation
- Prefix length (/24, /16)
- Hosts calculation
- Subnet mask
- Subnetting
